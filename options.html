DubWave

Real-time AI voice dubbing

Custom / OpenAI-compatible: enter either https://your-host/v1 or the full wss://.../v1/realtime endpoint. DubWave converts http(s) to ws(s), adds /realtime when needed, and sends the OpenAI Realtime event format. The server must support browser WebSocket authentication using the OpenAI-compatible realtime subprotocol or an api_key query parameter.

Gemini: Gemini Live Translation uses 16 kHz mono PCM input and 24 kHz PCM output. DubWave now keeps a continuous audio playback buffer and avoids playing each network packet as a separate audio buffer, which prevents pitch shifts, clicks, and packet-boundary noise. The dedicated Live Translation model controls its own translation voice.

LiveKit: choose LiveKit when a LiveKit room/agent is handling the AI pipeline. A participant token is required; do not put a LiveKit API secret in this extension.
